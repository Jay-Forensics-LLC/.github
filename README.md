## Featured projects

### HoneyTrace

**A clearer path from recorded activity to investigative context.**

HoneyTrace brings honeypot activity, incident classification, and supporting evidence into a connected workflow for security researchers and operators.

- **Observe** interactions with monitored services.
- **Connect** original events with normalized records and incident context.
- **Review** findings alongside the evidence that supports them.

**Status:** In development. Source is public; a public software release has not been announced.

[Explore HoneyTrace](https://jayforensics.com/honeytrace/) · [Browse source & development](https://github.com/Jay-Forensics-LLC/honeypot-v1.3-candidate)

### Luna AI Companion

**Exploring how an AI character develops a recognizable voice.**

Luna investigates conversational experiences built around distinct identities, coherent personalities, and expressive interaction.

- **Identity:** Give each character a defined personality.
- **Consistency:** Bring prompts, character definitions, and voice choices into alignment.
- **Expression:** Explore how text and voice contribute to the experience.

**Status:** In development. The source repository is private; access and release inquiries are welcome.

[Explore Luna](https://jayforensics.com/ai-companion/) · [Ask about access](mailto:rhunter654@pm.me?subject=Luna%20AI%20Companion%20access)
